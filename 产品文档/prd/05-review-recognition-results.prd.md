# 步骤4「核对识别结果」PRD

## 1. 页面范围

### 1.1 当前页面

- 页面名称：核对识别结果
- 所属模块：识别作业资料
- 页面路由/组件：/homework → 识别作业资料 → 核对识别结果
- 相关代码文件：
  - src/components/UploadQuestionDialog.tsx
  - src/app/homework/page.tsx
  - src/app/api/recognize-questions/route.ts
  - src/lib/ai-recognizer.ts
  - src/app/paper-edit/page.tsx

### 1.2 上级页面/上游入口

- 上级页面：首页作业资料识别入口（/homework）
- 入口位置：识别作业资料弹窗
- 进入方式：用户完成资料上传、选择识别方式和框选识别内容后，点击「开始识别」进入步骤4「核对识别结果」
- 传入数据：用户上传的题目资料、答案资料、步骤3框选区域、识别方式、识别结果和匹配结果
- 依赖状态：需要已经进入识别作业资料流程，并产生可供核对的题目识别结果

### 1.3 下级页面/下游流程

- 下级页面/下游流程：试卷编辑页（src/app/paper-edit/page.tsx）
- 触发方式：用户在步骤4点击「加入试卷」
- 传出数据：核对后的题目、题型、题干、题目图片、选项、填空空位、子题、答案和解析
- 后续状态：题目进入试卷编辑流程，用户可继续组卷和编辑
- 返回逻辑：从试卷编辑页返回时，步骤4保留当前核对状态用于继续调整

### 1.4 范围边界摘要

- 本文档覆盖：记录步骤 4「核对识别结果」的完整页面逻辑，覆盖匹配状态提示、题目卡片展示、题目卡片排序与删除、子题结构与编辑、答案/解析核对与关联、题型切换保护、图片模式与编辑模式切换、加入试卷等交互边界。
- 本文档不覆盖：见第 4.2 节范围边界

## 2. 功能概述

步骤4「核对识别结果」用于承接步骤3的框选识别结果，帮助老师核对题目、题型、作答结构、答案和解析，并在确认后加入试卷。页面同时支持仅识别题目模式和识别题目+答案模式，支持图片模式和编辑模式两类核对方式，并按不同题型展示对应的作答区域、答案区域、解析区域和子题结构。

## 3. 业务逻辑说明

### REVIEW_STEP-001 匹配状态提示（分步模式）

来源：代码事实 + 确认决策

#### 显示说明

题目+答案模式下，右侧面板顶部显示匹配状态提示条。存在待匹配题目时：「识别结果：共 X 道题目，已匹配答案 Y 题，待匹配答案 N 题（待匹配答案的题目，可在左侧框选答案/解析手动关联题目）」。全部匹配后：「全部题目已匹配答案和解析，可将题目加入试卷了~」。提示条始终完整展示，不可收起或展开。

页面内容：父题数量、已匹配答案数量、待匹配答案数量

状态反馈：
- 存在待匹配题目
- 全部匹配

#### 操作说明

提示条不可点击、不可收起、不可展开。存在待匹配题目时，用户可通过左侧框选答案/解析手动关联。

结果与流转：匹配统计根据已识别的题目、答案和解析数据计算。

异常边界：没有识别结果时不展示。

#### 验收标准

1. 存在待匹配题目时，提示条正确显示识别结果统计
2. 待匹配数量正确
3. 全部题目均已匹配答案/解析时，提示条显示「全部题目已匹配答案和解析，可将题目加入试卷了~」

### REVIEW_STEP-002 题目卡片展示（仅识别题目模式）

来源：代码事实 + 确认决策

#### 显示说明

仅识别题目模式下，右侧按题号展示每道题目。题号顺序以左侧资料页为准；补识别新增题按题号插入已有题目之间；重识别同题号题干时原位置覆盖。每张卡片含题号、题型、题目内容和图片预览，不展示答案/解析区域。

【6.20】仅识别题目 + 图片模式按“答题卡”思路展示父题作答结构：单选题展示 A/B/C/D 候选项，判断题展示“对/错”两个固定选项，填空题展示作答空位，父题为非客观题且没有子题时展示固定作答区，父题已有子题时只展示各子题作答区。

【6.20】仅识别题目 + 编辑模式下，题干区域展示可编辑文本框；填空题在题干上方显示「插入空位」按钮，题干内用绿色空线表示学生作答位置；单选题和判断题在题干下方展示绿色选项区域，选项区包含「选项」标题、关联图标、清空图标和选项内容输入框、增删选项，最多支持添加26个，最少减少至两个。

页面内容：题号、题型、题目内容、图片预览、【6.20】单选题候选项、【6.20】判断题对错选项、【6.20】填空作答空位、【6.20】固定作答区、【6.20】插入空位按钮、【6.20】选项关联图标、【6.20】清空选项图标、【6.20】增删选项入口

状态反馈：
- 图片模式：显示截图
- 编辑模式：显示识别文字
- 新增题：按题号插入
- 重识别题：原位置覆盖
- 【6.20】仅识别题目 + 图片模式：只展示作答结构，不展示标准答案和解析
- 【6.20】仅识别题目 + 编辑模式：题干、选项文案和子题内容可编辑

#### 操作说明

1、可切换图片模式查看截图或编辑模式修改文字。

2、两种模式下均可修改题型。

3、点击左侧题号框可定位到右侧对应题目，点击右侧题号可定位到左侧对应资料位置。

4、编辑模式下可修改题目内容。

5、可使用裁剪功能截取题目图片。

6、可为复合题添加子题。

7、补识别新增题：左侧框选漏掉题干后点击开始识别，新题卡按题号插入。

8、重识别已有题：重新框选完整题干后点击开始识别，原题卡覆盖更新。

结果与流转：题目数据来源于 AI 识别结果。新增题按题号插入，重识别同题号覆盖原题卡。用户编辑后更新本地状态，加入试卷时传递给下游。

异常边界：识别失败时停留在框选阶段。

#### 验收标准

1. 题目卡片正确展示
2. 右侧题号顺序应以左侧资料页题号顺序为准
3. 点击左侧题号框时右侧自动定位到对应题目
4. 单击右侧题号时左侧自动定位到对应资料位置
5. 图片/编辑模式可切换
6. 题型和内容可编辑
7. 裁剪功能可用
8. 第4步补识别新增题后应按题号插入列表
9. 第4步重识别重复题后应原位置覆盖
10. 【6.20】仅识别题目 + 图片模式下，父题应按单选题、判断题、填空题、非客观题分别展示对应作答结构
11. 【6.20】父题为非客观题且没有子题时，应展示固定作答区；父题已有子题时，只展示各子题作答区

### REVIEW_STEP-003 题目卡片展示（识别题目和答案模式）

来源：代码事实 + 确认决策

#### 显示说明

题目+答案模式下，右侧按题号展示每道题目。题号顺序以左侧资料页为准。每张卡片含题号、题型、题目内容、答案区域和解析区域。匹配状态用四种标签区分：「答案解析已匹配」「未匹配到答案」「未匹配到解析」「未匹配到答案和解析」。填空题按空位展示答案，解答题按子题结构展示子题答案和解析。补识别新增题按题号插入，重识别同题号题干时原位置覆盖。

【6.20】识别题目+答案 + 图片模式下，单选题和判断题父题在题干图片下方展示绿色选项区，选中项高亮，不显示独立答案输入区，但保留解析区；填空题展示按空位拆分的答案输入区；非客观题展示答案区和解析区。

页面内容：题号、题型、题目内容、答案、解析、匹配状态标签、子题答案/解析、【6.20】父题选项区、【6.20】选项关联图标、【6.20】候选项未匹配提示、【6.20】填空空位答案区

状态反馈：
- 答案和解析均匹配：显示「答案解析已匹配」
- 未匹配到答案：显示「未匹配到答案」
- 未匹配到解析：显示「未匹配到解析」
- 未匹配到答案和解析：显示「未匹配到答案和解析」
- 四种标签样式有区分
- 图片模式：显示截图
- 编辑模式：显示识别文字
- 新增题：按题号插入
- 重识别题：原位置覆盖
- 【6.20】题目+答案 + 图片模式客观题：选项承载标准答案，选中项高亮，独立答案区隐藏，解析区保留
- 【6.20】题目+答案 + 图片模式填空题：答案按空位逐个展示
- 【6.20】父题选项识别中：仅被操作的父题选项区显示「选项识别中...」
- 【6.20】候选项未匹配：显示「未匹配到合适的选项，请检查候选项」

#### 操作说明

1、可切换图片模式查看截图或编辑模式修改文字。

2、两种模式下均可修改题型、编辑答案和解析。

3、点击左侧题号框可定位到右侧对应题目，点击右侧题号可定位到左侧对应资料位置。

4、编辑模式下可修改题目内容。

5、可使用裁剪功能截取题目图片。

6、可为复合题添加子题。

7、未匹配答案时，可通过再次框选并点击开始识别更新结果；也可点击【答案】【解析】后的关联图标进入关联态，跨文件模式下自动定位到答案文件位置，无法定位到具体位置则定位到答案文件开始位置。

8、补识别新增题：左侧框选漏掉题干后点击开始识别，新题卡按题号插入。

9、重识别已有题：重新框选完整题干后点击开始识别，原题卡覆盖更新。

【6.20】10、识别题目+答案 + 图片模式下，单选题和判断题可点击选项按钮手动选中答案；点击「选项」标题后的关联图标后，在左侧答案区域框选内容，识别到可用选项时自动选中候选项，未匹配时提示「未匹配到合适的选项，请检查候选项」。

【6.20】11、父题选项关联识别时，只在当前父题选项区显示「选项识别中...」，识别完成后恢复常态。

【6.20】12、图片模式下减少选项数量不二次确认；如果原答案不在减少后的候选项范围内，按后续答案缺失或候选项未匹配规则处理。

【6.20】13、图片模式下填空题减少空位时，直接删除尾部空位及其答案，不二次确认。

【6.20】14、客观题图片模式加入试卷时，选中项作为标准答案保存，解析区内容作为解析保存。

结果与流转：题目数据来源于 AI 识别和答案匹配结果。新增题按题号插入，重识别同题号覆盖原题卡。用户编辑后更新本地状态，加入试卷时传递给下游。【6.20】图片模式客观题将选中选项作为标准答案，将解析区内容作为解析传递；填空题按空位顺序传递空位答案。

异常边界：识别失败时停留在框选阶段。【6.20】选项关联未匹配到候选项时保留原有候选项并提示「未匹配到合适的选项，请检查候选项」；减少选项或空位后如出现答案缺失，加入试卷时按答案/解析缺失规则处理。

#### 验收标准

1. 题目卡片含答案和解析区域
2. 右侧题号顺序应以左侧资料页题号顺序为准
3. 四种答案/解析匹配状态标签正确显示且样式有区分
4. 点击左侧题号框时右侧自动定位到对应题目
5. 单击右侧题号时左侧自动定位到对应资料位置
6. 未匹配答案时可通过再次框选并开始识别更新结果
7. 答案/解析关联图标可引导用户定位答案文件并进入关联状态
8. 填空题按空位显示答案
9. 解答题显示子题结构
10. 图片/编辑模式可切换
11. 第4步补识别新增题后应按题号插入列表
12. 第4步重识别重复题后应原位置覆盖
13. 【6.20】识别题目+答案 + 图片模式下，单选题和判断题父题显示选项区，选中项高亮，答案输入区隐藏，解析区保留
14. 【6.20】父题选项关联识别时只在当前父题选项区显示「选项识别中...」
15. 【6.20】候选项未匹配时显示「未匹配到合适的选项，请检查候选项」
16. 【6.20】减少选项数量不弹窗，减少填空空位时直接删除尾部空位及答案

### REVIEW_STEP-004 子题结构与编辑

来源：代码事实 + 确认决策

#### 显示说明

复合题型（解答题、完形填空、阅读理解等）支持子题结构。识别时系统自动拆分大题的子题，右侧展示时已添加好子题，每个子题含序号（①②③...）和自动匹配的题型；题目+答案模式下还展示答案和解析区域。父题无需显示子题匹配进度标签。乐课网资源库中无子题的大题不显示【+子题】按钮。

【6.16】填空题（含父题和子题）题干下方显示「+插入空位」按钮和空位数量匹配状态文案（题干空位与答案空位一致/题干少/题干多三种状态）。点击「插入空位」后在题干光标位置插入下划线，答案区自动增加对应空位输入框。

【6.20】仅识别题目 + 图片模式下，父题题干下方的子题区域按题型展示作答结构：单选题展示 A/B/C/D 候选项，判断题展示“对/错”两个固定选项，填空题展示作答空位，非客观题展示固定作答区，父题题干上方不再重复展示紧凑子题题型信息。

【6.20】仅识别题目 + 编辑模式下，子题区域展示子题序号、子题题型选择器和删除图标；客观题子题展示绿色选项编辑区，非客观题子题展示绿色「子题题干」编辑区；填空题子题题干区显示「插入空位」按钮和绿色空线编辑能力；仅题目模式下不展示子题答案和解析输入区。

【6.20】识别题目+答案 + 图片模式下，客观题子题与父题保持一致：展示绿色选项区，选中项高亮，不显示独立答案区，但保留独立解析区；填空题子题按空位展示答案输入区。

页面内容：子题序号、子题题型、子题答案、子题解析、+子题按钮、删除子题按钮、【6.16】+插入空位按钮、【6.16】空位匹配状态文案、【6.20】单选题候选项、【6.20】判断题对错选项、【6.20】填空作答空位、【6.20】固定作答区、【6.20】题目+答案模式子题选项区、【6.20】题目+答案模式子题解析区、【6.20】题目+答案模式子题填空空位答案区

状态反馈：
- 资源库无子题的大题：不显示【+子题】
- 新增子题：空子题
- 【6.16】空位匹配状态：一致（灰色正常文案）、题干空位少（橙色警告）、答案空位少（蓝色提示），文案仅在编辑模式下显示
- 【6.16】图片模式下插入空位：不修改图片内容，仅在答案区末尾新增一个答案输入框
- 【6.16】删除空位/下划线：两侧独立操作不联动
- 删除子题确认弹窗
- 【6.16】填空题多空位：答案区按空位逐个显示输入框，每个空位独立填写
- 【6.16】子题删除：顶部标记条和底部答案/解析区各有一个删除入口
- 【6.16】子题编号：使用带圈数字①②③...⑩，超过10个回退普通数字
- 【6.20】仅识别题目 + 图片模式：子题下方只展示作答结构，不展示答案/解析输入区
- 【6.20】数量达到上限：选项增加入口提示「最多支持 26 个选项」，空位增加入口提示「最多支持 20 个空位」
- 【6.20】仅识别题目 + 编辑模式：显示可编辑子题题干、选项或空位结构，不展示子题答案和解析输入区
- 【6.20】题目+答案 + 图片模式客观题子题：选项区显示答案，解析区保留
