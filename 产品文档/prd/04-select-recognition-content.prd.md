# 步骤3「选择识别内容」PRD

## 1. 页面范围

- **当前页面**：步骤3「选择识别内容」
- **所属模块**：识别作业资料
- **进入方式**：步骤2 选择识别方式后进入
- **下级页面**：步骤4「核对识别结果」（点击「开始识别」后）

## 2. 范围边界

- **覆盖**：资料选框层（识别框呈现/操作/回退）、右侧悬浮操作（开始识别/清空/取消识别）、右侧空状态、框选统计、文件用途弹窗、补充资料/更换资料/重新上传、更多工具面板、增量识别进度条

## 3. 业务逻辑

### BOX_STEP-010 资料预览区选框层：呈现、操作与回退

来源：代码事实 + 确认决策

**显示说明**

左侧资料预览区按页展示上传资料。每页资料图片上方覆盖识别框：选中框为绿色边框和浅绿色底色，左上角显示绿色圆形勾选按钮；未选中框为灰色边框和浅色底色。【6.15】每个框右上角显示状态标签（待识别/识别中/已识别/待重新识别/识别失败），识别到真实题号后在框外边缘显示「原卷：第 X 题」，未识别到题号时显示「原卷：第 ? 题」。【6.15】框选区域可显示四角和四边绿色调整手柄。拖拽画框时显示绿色虚线临时框。题目+答案（不同文件）模式下资料页顶部显示「题目」或「答案」文件标签，优先展示题目文件，再展示答案文件。

**状态变化：**
- 首次进入：自动切题完成后框直接显示并默认选中
- 【6.15】自动切题目标：以完整题目资料块为目标，题干、选项、附图、表格、紧跟题后的答案解析可以一起框入
- 【6.15】题目+答案（同文件）模式：答案解析紧跟题目时允许同框，答案集中在后面时题目框只框题干，答案通过匹配或手动关联处理
- 题目+答案（不同文件）模式：默认只对题目文件自动切题，答案文件不自动切题
- 【6.15】答案文件用户可手动画答案/解析框，未手动画时由全局答案匹配承接
- 自动切题中资料区显示加载态，完成后展示框
- 【6.15】自动切题失败或未检测到内容：不显示自动框，用户可手动画框
- 继续上传后新文件追加到同类文件后方，新框默认选中
- 待识别：框正常显示并可操作；识别中：框不消失但不可操作；已识别：框默认未选中
- 【6.15】步骤4新增框：默认选中，状态为「待识别」，识别完成前不显示题号标签
- 【6.15】步骤4已识别框调整：只允许四边/四角微调大小，不允许整体移动到其他题目区域
- 【6.15】题号已识别显示「原卷：第 X 题」，题号来自识别结果或用户编辑后的题号；已识别框的题号标签可点击定位到右侧对应题目卡片
- 【6.15】题号未识别显示「原卷：第 ? 题」，不得按画框顺序或页面顺序推测题号；未识别框的题号标签不可点击（点击提示「该框尚未识别，暂无对应题目」）
- 【6.15】步骤3题号标签显示范围：只对在上一步选中过的框根据真实识别结果显示标签
- 步骤4返回步骤3：框选区域和题目数据保留，所有框取消选中

**操作说明**

1、用户在资料空白处按住鼠标拖动可手动画出识别框，松开后新框默认选中。
2、点击左上角圆形勾选按钮可切换单个框的选中状态。
3、【6.15】拖动框内部可移动未识别框位置，拖动四角或四边手柄可调整大小。
4、【6.15】步骤4已识别框只允许拖动四边/四角微调大小，不允许整体移动；如需识别新题目，必须新增框。
5、点击红色删除按钮可删除单个框，也可用右侧「清空」悬浮入口删除全部框。
6、【6.15】题目+答案（同文件）模式下，资料版式决定框选范围：答案解析紧跟题目时允许同框；答案集中在后面时题目框只框题干，答案通过匹配或手动关联处理。
7、题目+答案（不同文件）模式下，系统默认只对题目文件自动切题；答案文件不默认生成框，用户可手动画答案/解析框。
8、用户未在答案文件上手动画答案/解析框时，系统继续通过全局答案匹配从答案文件中提取并关联答案。
9、【6.15】点击「开始识别」或「更新识别结果」时，只有当前选中的框进入识别；识别中的框不可勾选、拖动、缩放或删除，也不能新画框。
10、【6.15】用户框选区域过小、空白、跨题或包含多题时，前端不强拦截；AI 按框内主要题目忠实识别，若框内包含多题则返回多题结构，由右侧结果承接。
11、【6.15】跨页题支持作为业务场景，但不通过连续拖拽形成跨页框；后续通过「追加本题下一页内容」能力把多个框合并为同一道题来源。
12、【6.15】框外题号只使用系统已获得的真实题号；未获得时显示「原卷：第 ? 题」，不得推测题号。
13、【6.15】已识别框的题号标签可点击，点击后右侧滚动定位到对应题目卡片并高亮；未识别框的题号标签点击后提示「该框尚未识别，暂无对应题目」。
14、【6.15】步骤3删除单个框无确认弹窗，直接删除；步骤4删除框或题卡弹出确认弹窗（描述：「删除该框后，右侧对应的题目卡片也将一并删除，是否继续？」），确认后两侧同步删除。删除题卡时关联的答案数据一并删除。
15、【6.15】删除操作不触发「更新识别结果」按钮状态变化，仅新增、移动、缩放框才触发。
16、【6.15】右侧题卡上题号标签点击定位到左侧框并高亮，点击题号标签旁铅笔图标进入编辑态修改题号。
17、【6.15】编辑题号时逐位实时更新，编辑后不进行题号冲突检测，允许重复编号存在。

**后续流程**

识别框来自自动切题结果或用户手动画框。框的位置、大小、所在页、文件角色持续保留在本流程中。开始识别或更新识别结果时，系统读取已选中框并裁剪对应区域，识别完成后题目数据展示到右侧核对区，真实题号回写到对应框。【6.15】左侧框与右侧题卡优先通过框 ID / 题卡 ID 绑定，题号只是用户可见标识；题号修改只同步显示，不改变底层绑定关系。步骤4返回步骤3时，框选区域、题号和已识别题目保留，只清空选中状态。

**异常边界**

【6.15】自动切题失败或服务未配置时不阻断流程，左侧资料正常展示，并提示「自动框选失败，请手动框选需要识别的题目区域。」题目+答案（不同文件）模式下，答案文件无手动画框不阻塞开始识别，由全局答案匹配承接。【6.15】自动切题中和识别中禁止新增、删除、移动、缩放框，页面只允许滚动查看；用户尝试操作时提示「正在处理资料，请等待完成后再调整框选区域。」【6.15】步骤4已识别框被整体拖动时提示「已识别框仅支持边界微调；如需识别新的题目，请新增框选区域。」取消识别时，已框选区域不清空，识别中的框退出锁定状态恢复可操作。识别失败时保留原框和原有题号信息，右侧显示失败信息。【6.15】未识别到题号时框外持续显示「原卷：第 ? 题」，直到后续识别或编辑题号后获得真实题号。

### BOX_STEP-002 开始/更新识别按钮

来源：代码事实 + 确认决策

**显示说明**

资料预览区右侧中部显示绿色圆形悬浮球和下方文字按钮。【6.15】步骤3文案为「开始识别」；步骤4继续新增或调整框选后，文案为「更新识别结果」。有选中框且不在自动切题或识别中时为绿色可点击，无选中框或处理中时置灰。

**操作说明**

1、步骤3点击后，系统根据已选中的框裁剪图片区域，调用 AI 识别，进入步骤4。
2、仅识别题目模式：选中框按题目处理，右侧只展示题干。
3、题目+答案模式：题目框走完整识别，答案框走答案/解析提取，右侧展示题干、答案和解析。
4、【6.15】步骤4新增框后，新框默认选中，状态为待识别，但不显示题号标签；用户点击「更新识别结果」后识别该框并展示识别到的题号。
5、【6.15】步骤4调整已有框后，只识别被选中且处于待识别或待重新识别状态的框；识别完成后通过框 ID / 题卡 ID 更新对应题卡，题号只作为页面可见标识，不作为唯一绑定依据。
6、【6.15】步骤4移动、缩放、新增框后该框自动选中，确保「更新识别结果」按钮立即可用；2px 以内的微调不触发状态变化。
7、【6.15】步骤4每次移动已识别框时弹出提示：「已识别框仅支持边界微调；如需识别新的题目，请新增框选区域」。
8、【6.15】更新识别完成后，右侧自动滚动到第一张被更新的题卡，被更新题卡闪烁高亮（新增题绿色闪烁、重识别题蓝色闪烁，持续2.5秒）。

**异常边界**

【6.15】自动切题中和识别中禁止新增、删除、移动、缩放框，页面只允许滚动查看；用户尝试调整时提示「正在处理资料，请等待完成后再调整框选区域。」识别中可点击「取消识别」退出识别状态，回显识别前的选框和选中状态。识别失败时保留原框和选中状态，右侧显示错误信息；同时保留用户在点击「更新识别结果」前的框状态（待重新识别标签继续显示、框选范围保留、选框保持选中），用户可调整后再次重试。

### BOX_STEP-011 增量识别进度条

来源：代码事实 + 确认决策

**显示说明**

【6.15】第4步已有识别结果后，继续新增框或微调已有框并点击「更新识别结果」时，右侧面板不再清空为全屏加载动画，而是在模式切换按钮下方显示细进度条（含加载动画、进度文案和取消按钮）。提示文案按场景区分：
- 【6.15】场景A（仅新增框选）：「正在识别 X 个新增区域...」
- 【6.15】场景B（仅重新识别已识别题目）：「正在重新识别 X 道题目...」
- 【6.15】场景C（混合新增+重新识别）：「正在识别 X 个区域（含 Y 道重新识别）...」

【6.15】已有题目卡片在进度条下方保持可见可滚动；被重新识别的题目卡片显示「识别中」遮罩。识别完成后进度条消失，新增或更新的题目卡片高亮闪烁。首次识别（无已有题目）保持全屏加载动画。

**操作说明**

1、【6.15】系统自动检测选中框哪些为新增、哪些为待重新识别。
2、【6.15】补画漏掉题目区域：作为新增处理，识别完成前不显示题号标签，识别完成后按资料来源位置进入右侧结果。
3、【6.15】微调已有题目边界：作为重新识别处理，对应卡片识别期间半透明+「识别中...」遮罩，不可操作。
4、【6.15】不受影响的题目卡片保持正常显示，可滚动查看但不可编辑。
5、【6.15】识别期间不允许编辑任何题目，也不允许新增、删除、移动或缩放左侧框。
6、【6.15】取消识别后，被重识别的题目恢复旧内容，新增框选不产生新题目，进度条消失。
7、【6.15】识别完成：重识别题目恢复不透明并替换新内容，蓝色边框闪烁2.5秒；新增题目按资料来源位置插入，绿色边框闪烁2.5秒。

**后续流程**

【6.15】识别结果通过 SSE 流式返回。新增题目按资料来源位置插入已有列表；重新识别结果通过框 ID / 题卡 ID 替换原题卡。题号是页面可见标识，不能作为唯一覆盖依据。

**异常边界**

首次识别保持全屏加载动画。【6.15】取消识别不丢失已有题目数据。识别失败时保留原题卡和原框选状态，用户可重新调整后再次更新识别结果。

### BOX_STEP-004 文件用途分配弹窗

来源：代码事实 + 确认决策

**显示说明**

确认后清空框选、识别模式、文件用途和识别结果，回到步骤1并回显已上传文件和识别范围。取消后保持当前状态。

### BOX_STEP-008 继续上传后自动切题提示

来源：代码事实 + 确认决策

**显示说明**

继续上传追加新文件后，左侧资料预览区顶部显示蓝色提示条「正在处理新文件...」，带旋转加载动画。仅在追加后切题期间显示，首次进入时和切题完成后不显示。

**操作说明**

提示条不可点击、不可交互。

### BOX_STEP-013 更多工具面板

来源：代码事实 + 确认决策

**显示说明**
