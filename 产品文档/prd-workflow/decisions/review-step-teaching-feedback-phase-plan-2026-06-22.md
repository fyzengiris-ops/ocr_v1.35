# 第4步核对识别结果教研反馈调整方案（2026-06-22）

## 适用页面

- 页面：`/homework`
- 分支：`feat/new-recognition-flow`
- 主要文件：`src/components/UploadQuestionDialog.tsx`
- 当前预览：`http://localhost:3000/homework`

## 适用范围规则

1. 标注“所有模式”时，表示以下四种组合都适用：
   - 仅识别题目 + 图片模式
   - 仅识别题目 + 编辑模式
   - 识别题目+答案 + 图片模式
   - 识别题目+答案 + 编辑模式
2. 只标注“图片模式”时，表示仅识别题目 + 图片、识别题目+答案 + 图片都适用。
3. 只标注“编辑模式”时，表示仅识别题目 + 编辑、识别题目+答案 + 编辑都适用。
4. 明确标注具体组合时，仅该组合适用。

## 本次需求整理

1. 所有模式下，单选题/多选题的选项数调整入口统一放到题型后面，删除独立选项区右侧的添加/减少选项入口。
2. 图片模式下，填空题的空数调整入口统一放到题型后面。
3. 编辑模式下，填空题的“插入空位”入口统一放到题型后面，删除图片/编辑切换下方的旧按钮。
4. 所有模式下，解答题/复合题的添加子题入口统一放到题型后面，删除父题题干下方的“+子题”按钮，保留子题之间的“+插入子题”按钮。
5. 仅识别题目 + 图片模式下，解答题添加子题后，在题型下方、图片题干上方集中展示子题信息，例如“（1）单选题、（2）计算题”，支持改子题题型、删除子题；客观子题可调整选项数量。
6. 仅识别题目 + 编辑模式下，解答题的客观子题在选项区域上方补充“子题题干”区域，效果类似英语阅读理解子题。
7. 仅识别题目 + 图片模式下，所有题型都去掉题干下方类似答题卡的信息区域。
8. 识别题目+答案 + 编辑模式下，父题客观题去掉独立答案区，选项区域改为可选中，选中项作为答案，解析区保留。
9. 识别题目+答案 + 编辑模式下，解答题下的客观题子题同样去掉独立答案区，选项区域改为可选中，选中项作为答案，解析区保留。
10. 英语学科 + 仅识别题目 + 完型填空 + 图片模式下，题型后显示统一选项数设置，后面显示快捷设置子题数量；题型下方、图片题干上方集中展示子题信息。子题可改题型，但子题单选题不单独调整选项数。
11. 英语学科 + 仅识别题目 + 完型填空 + 编辑模式下，题型后显示统一选项数设置，后面显示快捷设置子题数量。
12. 英语学科 + 阅读理解的四种模式下，题型后显示统一选项数设置，后面显示快捷设置子题数量；其中题目+答案 + 图片模式在题型下方、图片题干上方集中展示子题信息。子题单选题不单独调整选项数。

## 分阶段实现

### 第一阶段：布局入口与展示结构

第一阶段只调整页面入口位置和展示结构，不改变题目+答案 + 编辑模式下客观题的答案语义。

范围：

1. 题型后统一显示结构操作入口：
   - 选择题选项数
   - 图片模式填空空数
   - 编辑模式填空插入空位
   - 复合题添加子题
   - 英语完型填空/阅读理解的统一选项数和快捷子题数量
2. 删除旧入口：
   - 选项区右侧选项数加减
   - 编辑题干上方插入空位按钮
   - 图片模式答案/作答区里的空数加减
   - 父题题干下方/子题列表末尾“+子题”
3. 仅识别题目 + 图片模式隐藏题干下方答题卡式信息区。
4. 新增或复用题型下方、图片题干上方的集中子题信息区。
5. 仅识别题目 + 编辑模式下，解答题客观子题补充“子题题干”区域。

### 第二阶段：客观题答案语义

第二阶段再调整题目+答案 + 编辑模式下客观题答案逻辑。

状态：已实现（2026-06-22）。

范围：

1. 父题单选题/多选题/判断题隐藏独立答案区。
2. 父题选项区支持选中态，选中项写入答案。
3. 解答题下客观题子题隐藏独立答案区。
4. 子题选项区支持选中态，选中项写入子题答案。
5. 多选题支持多选，答案按选项字母顺序保存。

## 验收建议

1. 第一阶段验收页面结构：
   - 各题型操作入口是否都在题型后面。
   - 旧入口是否已移除。
   - 仅识别题目 + 图片模式题干下方是否不再出现答题卡式区域。
   - 集中子题信息区是否出现在正确位置。
   - 英语完型填空和阅读理解的统一选项数/子题数量入口是否正确。
2. 第二阶段验收数据语义：
   - 题目+答案 + 编辑模式下客观题选项是否可选中。
   - 选中后加入试卷保存的答案是否正确。
   - 多选题多选保存是否正确。
   - 解析区域是否保留。
