## 文档说明

## 第一部分：系统总览

### 1.1 项目背景

本项目为 OCR 作业识别专项优化，解决上传效率低、超限场景体验差、答案匹配成本高、异常流程易中断四大痛点。

### 1.2 系统目标

通过流程和交互优化支撑 OCR 组卷、AI 批改等核心业务规模化落地。当前文档覆盖从 AI 小乐入口到试卷编辑页交接前后的主要链路：

1. 教师在作业管理页打开 AI 小乐。
2. 教师通过 AI 小乐发起"识别作业资料"任务，直接进入步骤条弹窗。
3. 在步骤 1（上传资料）中选择本地上传或资源库资料，并确认学段学科、页码范围。
4. 在步骤 2（选择识别方式）中选择识别模式，多文件时分配文件用途。
5. 在步骤 3（选择识别内容）中检查或手动画框，并启动识别。
6. 在步骤 4（核对识别结果）中核查题目信息、答案解析、子题结构和图片裁剪结果。
7. 点击"加入试卷"，进入试卷编辑页继续编辑。

## 第二部分：各模块详情

### 模块一：AI 小乐任务入口（M1）

#### 页面组成

AI 小乐侧边面板由 `/homework` 和 `/paper-edit` 打开。当前识别作业资料链路的主要入口在 `/homework`。

- 底部输入框和发送按钮保留但禁用，当前版本不支持自由文本发起任务。

### 模块二：上传录题流程（M2）

模块二由四个连续步骤组成：上传资料 → 选择识别方式 → 选择识别内容 → 核对识别结果。

```mermaid
flowchart LR
  A["步骤 1 上传资料"] --> B["步骤 2 选择识别方式"]
  B --> C["步骤 3 选择识别内容"]
  C --> D["步骤 4 核对识别结果"]
  D --> E["加入试卷"]
```

#### 步骤 1：上传资料（P2）

**页面职责：**

- 接收从 AI 小乐进入的识别任务。
- 提供本地上传和我的资源库两个资料来源 Tab。
- 支持文件格式校验、页数检测、重复文件拦截。
- 展示已有资料页数提示（蓝色/红色条）和 24 页上限校验。
- 展示已上传文件列表，支持删除和识别范围调整。
- 要求选择学段学科，适用于本次任务所有文件。
- 点击"下一步"提交文件并进入步骤 2。

##### 仅识别题目模式及通用核查

###### 1. 图片模式与编辑模式切换（`REVIEW_STEP-006`）

来源：代码事实 + 确认决策；变更日期：【6.24】

**显示说明**

右侧顶部提供「图片模式」和「编辑模式」切换按钮：图片模式展示题目截图，编辑模式展示可编辑的识别文字，并提示「请注意甄别AI识别内容」。
【6.24】进入步骤 4 时，默认选中编辑模式。顶层处于图片模式时，单题仍可独立显示编辑模式。

**状态反馈**

1. 【6.24】进入步骤 4：默认编辑模式选中
2. 图片模式选中：绿色高亮
3. 编辑模式选中：绿色高亮
4. 切换中：显示加载动画

**操作说明**

【6.24】进入步骤 4 后默认进入编辑模式；用户仍可点击图片模式查看截图，或点击编辑模式编辑识别文字、题干、选项、子题和填空空位。
【6.20】两种模式仅切换视图：切回图片模式不弹窗，已编辑内容和图片裁剪结果均保留。点击步骤 3 的确认弹窗后，清空编辑的图片和文字数据。
【6.21】顶层图片模式下仍可将单题切为编辑模式。
仅当左侧已识别选框被调整并再次选中后，点击「更新识别结果」才显示确认弹窗。标题为「确认更新识别结果吗？」，弹窗文案为「被选中的待重新识别的题目，其题干、答案、解析等内容将全部重置」；确认后进入识别并以最新结果替换该题图片和编辑内容，取消则留在当前状态。

**后续流程**

视图切换保留当前题目的图片、识别文字、答案、解析和用户修改内容；更新识别确认后才替换对应题目的图片和编辑内容。

**异常边界**

【6.21】没有待更新识别结果时，切换图片模式或编辑模式不触发内容替换。


**验收标准**

1. 两种模式可切换
2. 切换有加载动画
3. 编辑模式可编辑内容
4. 图片模式显示截图
5. 【6.20】切回图片模式不弹窗且保留编辑内容
6. 【6.20】调整已识别选框并点击更新识别结果时，应显示「确认更新识别结果吗？」弹窗；点击取消不进入识别状态，点击确认并识别完成后替换对应题目的图片内容和编辑模式内容
7. 点击步骤条步骤3的确认弹窗后清空用户编辑的图片和文字数据
8. 【6.21】顶层图片模式下，单题应可切换为编辑模式
9. 【6.21】确认更新识别结果后，应同时替换对应题目的图片内容和编辑模式内容

###### 2. 题目卡片展示（仅识别题目模式）（`REVIEW_STEP-002`）

来源：代码事实 + 确认决策；变更日期：【6.23】

**显示说明**

仅识别题目模式下：右侧展示题卡的顺序，根据左侧选框在资料中的位置，按从上至下、从左至右显示；卡片包含「原卷：第 X 题」、题型和题干，不展示答案/解析。题号排序、补识别插入和重识别覆盖规则见「题卡排序规则」。
【6.23】图片模式展示题目截图，编辑模式展示可编辑题干，题干内容均随实际内容自然展开；各题型在图片模式和编辑模式下的作答结构、关联与回填规则见「仅识别题目：按题型核对」。

**状态反馈**

1. 【6.23】图片模式：显示题目截图；复合题有子题时显示子题概览区
2. 【6.23】编辑模式：显示识别文字和可编辑的选项文案
3. 【6.20】编辑模式：选项识别中时仅当前选项区显示「选项识别中...」

**操作说明**

用户可切换图片/编辑视图、编辑题号和题干；左侧题号框与右侧「原卷：第 X 题」可双向定位，题号可输入正整数。
【6.23】图片模式可裁剪题目图片；编辑模式可编辑题干，填空题在题干下方插入空位，单选题默认 A/B/C/D，判断题固定 A.对、B.错。
【6.20】编辑模式下，点击选项关联图标后框选题干选项，系统拆分并回填当前题选项文案；再次点击可取消，清空图标只清除选项文案。
【6.21】已识别选框即使调整为完全不同内容，点击「更新识别结果」仍覆盖其当前对应题卡。

**后续流程**

用户编辑结果保存在当前题卡；加入试卷的数据规则见「加入试卷」。

**异常边界**

识别失败时停留在框选阶段。


**验收标准**

1. 题目卡片正确展示
2. 右侧题号顺序应以左侧资料页题号顺序为准
3. 点击左侧题号框时右侧自动定位到对应题目
4. 单击右侧题号时左侧自动定位到对应资料位置
5. 图片/编辑模式可切换
6. 题型和内容可编辑
7. 【6.20】仅识别题目 + 编辑模式下，单选题和判断题选项内容可编辑，选项识别中应显示加载态
8. 【6.20】仅识别题目 + 编辑模式下，填空题点击插入空位后应在题干光标位置插入绿色空线并同步空位数量
9. 裁剪功能可用
10. 第4步补识别新增题后应按题号插入列表
11. 第4步重识别重复题后应原位置覆盖

来源：代码事实；变更日期：【6.23】

**显示说明**

**操作说明**

**AI 提示词与回填**

**P1 图片模式选项/内容识别**

- 触发条件：框选题目文件；图片模式的选项或子题内容关联。
- 回填结果：有选项标记时回填选项；无选项标记时回填题干或子题题干。

```text
你是教育内容识别专家。用户框选了一个资料图片区域，请精准识别其中的文字内容，并按以下规则分类处理。

## 处理规则

### 规则1：存在选项标记
如果识别到的文字包含选择题的选项标记（A. / A、/ (A) / ① / A) / A．/ ㈠ 等格式）或判断题标记（对/错、正确/错误、√/×、T/F）：
- **hasOptions** 设为 true
- 将内容按选项标号拆分为独立选项
- 每个选项提取：**label**（标号本身，如 "A"/"B"/"对"/"错"/"①"/"②"）和 **content**（该选项对应的文字内容，不含标号）
- 选项内容跨行时保持完整性
- **plainContent** 填空字符串

### 规则2：无选项标记
如果识别到的文字不包含任何选项标记，仅为连续的文字内容：
- **hasOptions** 设为 false
- **plainContent** 填完整的识别文字（保留换行结构）
- **options** 填空数组

### 输出格式（严格JSON，不要其他内容）
{
  "hasOptions": true,
  "options": [{"label": "A", "content": "该选项对应的文字内容"}],
  "plainContent": ""
}

或

{
  "hasOptions": false,
  "options": [],
  "plainContent": "完整的文字内容"
}

### 约束
1. 选项标号不限于ABCD，也可能是①②③④、对/错、√/×、T/F等
2. label 只保留标号本身，不要附带标点（"."、"、"、"）"等）
3. content 是该选项的实际文字，不含标号
4. 数学公式使用纯文本：分数 a/b，上标 x^2，下标 x_1
5. 禁止 LaTeX
6. 只输出JSON
```

**P2 编辑模式选项/内容识别**

### 规则2：无选项标记（纯题干/子题文字）

- **hasOptions** 设为 false
- **plainContent** 填完整文字（保留段落结构）
- **options** 填空数组

### 输出格式（严格JSON）

  "plainContent": ""

3. 跨行选项内容合并为完整文字
4. 保留原文中关键信息（数字、公式符号、特殊字符）

6. 只输出JSON

**P3 编辑模式答案/解析识别**

- 触发条件：框选答案文件；编辑模式答案或解析关联。
- 回填结果：拆分后分别回填答案和解析；无法拆分时保留完整内容。

```text
你是教育内容识别专家。用户框选了一个资料图片区域，请识别其中的内容，判断是否同时包含"答案"和"解析"两部分，并按要求拆分。

## 处理规则

### 规则1：内容可区分出"答案"和"解析"
如果识别到的文字中能明确区分为答案和解析两部分（常见特征："答案：xxx 解析：xxx" / "【答案】xxx 【解析】xxx" / 前半段为简洁答案、后半段为详细解释说明等）：
- **hasSplit** 设为 true
- **answer**：提取答案部分的纯文字（去除"答案：""【答案】"等标记词）
- **analysis**：提取解析部分的纯文字（去除"解析：""【解析】"等标记词）
- 答案通常较短（几个字/一个选项字母/一个数字），解析通常较长
- 对于选择题，答案只返回选项字母（如 "A"）；对于判断题，返回 "对"/"错"；其他题型返回完整答案文字

### 规则2：内容无法区分答案和解析
如果识别到的文字是连续的、无法明确拆分出独立的答案和解析：
- **hasSplit** 设为 false
- **content** 填完整的识别文字

### 输出格式（严格JSON）
{
  "hasSplit": true,
  "answer": "答案文字",
  "analysis": "解析文字",
  "content": ""
}

或

{
  "hasSplit": false,
  "answer": "",
  "analysis": "",
  "content": "完整文字内容"
}

### 边界情况
- 只有"答案："标记而无"解析："标记 → answer 填答案内容，analysis 填空，hasSplit 为 true
- 只有"解析："标记而无"答案："标记 → analysis 填解析内容，answer 填空，hasSplit 为 true
- 答案和解析标记词本身不包含在返回内容中

### 约束
1. 数学公式使用纯文本，禁止LaTeX
2. 只输出JSON
```

### 模块三：试卷编辑页交接（M3）

- 入口：步骤 4 右上角"加入试卷"。

## 第三部分：操作路径

### 3.1 主路径：仅识别题目

1. 打开 AI 小乐 → 点击"帮我识别作业资料" → 直接进入步骤条弹窗步骤 1。
2. 上传文件或选择资源库资料，选择学段学科。
3. 点击"下一步"进入步骤 2。
4. 选择"仅识别题目"。
5. 进入步骤 3，系统自动切题，默认选中框。
6. 点击"开始识别"。
7. 进入步骤 4，核查题目内容和图片。
8. 点击"加入试卷"进入 `/paper-edit`。

### 3.2 主路径：识别题目和答案

1. 上传文件，选择学段学科，进入步骤 2。
2. 选择"题目+答案（同文件 或 不同文件）"。
3. 不同文件模式时先完成文件用途分配。
4. 步骤 3 框选识别，右侧展示题干+答案+解析。
5. 步骤 4 核查匹配状态，处理未匹配答案。
6. 点击"加入试卷"，有缺口时二次确认后进入 `/paper-edit`。

### 3.3 分支路径：补充资料

- 步骤 3 "更多工具" → "补充资料" → 打开资料选择弹窗（仅本地上传）。
- 仅识别题目/同文件模式：直接自动切题。
- 不同文件模式：弹出文件用途分配弹窗，取消则撤回补充文件。

### 3.4 分支路径：更换资料 / 重新上传

- 更换资料：返回步骤 1，已有识别结果时需确认清空。
- 重新上传：确认后清空全部数据，回到步骤 1 并回显文件列表。

### 3.5 分支路径：手动关联答案

- 步骤 4 点击题卡内【答案】或【解析】后的关联图标进入关联态。
- 跨文件模式自动定位到答案文件。
- 左侧框选内容后识别结果自动填入对应区域。

### 3.6 分支路径：返回录题

- 试卷编辑页点击"返回录题" → 回到 `/homework` → 恢复弹窗。

## 第四部分：全局规则

### 4.1 权限
- 沿用作业管理页 AI 小乐识别资料入口的使用权限。

### 4.2 资料规则
- 支持 PNG/JPG/JPEG/PDF/DOC/DOCX，不支持格式拦截。
- 重复文件拦截。页数检测失败文件自动移出。
- 本次识别任务最多 24 页。页码范围仅支持单个连续范围。

### 4.3 学科规则
- 学段学科必选，适用于本次任务所有文件。
- 加入试卷后试卷带有学科信息。

### 4.4 模式规则

| 模式 | 适用场景 | 多文件处理 |
|------|---------|-----------|
| 仅识别题目 | 只含题目不含答案 | 全部按题目文件处理 |
| 题目+答案（同文件） | 题目和答案在同一资料 | 按同一资料内处理 |
| 题目+答案（不同文件） | 题目和答案分文件 | 需分配文件用途 |

### 4.5 异常规则
- 格式不支持 → 拦截提示。页数检测失败 → 移出文件。
- 超 24 页 → 禁用提交。自动切题失败 → 允许手动画框。
- 识别失败 → 不生成模拟数据，停留在框选阶段可重试。
- 答案无法拆分 → 保留父题区并提示人工拆分。
- 加入试卷有缺口 → 允许带缺口加入但需二次确认。
